# TaskPulse

An advanced Android task monitoring app built with Kotlin, Jetpack Compose, MVVM, Hilt, Room, and Material 3.

## Features
- Animated splash + onboarding
- Dashboard with battery, RAM, storage, and performance score
- App usage tracking and intelligent suggestions
- Focus mode, reports, settings, and premium UI
- Room persistence and Hilt dependency injection

## Build
1. Open this folder in Android Studio.
2. If Gradle wrapper is missing, use your installed Gradle or generate wrapper.
3. Build and run on a device or emulator with Android 24+.

## Notes
- The current implementation includes local authentication UI and usage tracking examples.
- Firebase support is added as dependencies and can be wired with a real project config.
